# Handy Codex 0.9.11

This independent Handy fork adds fixes for Codex transcription and cloud post-processing.

- Codex transcription now uses WebM/Opus audio. Install FFmpeg with libopus before using this mode.
- Authentication and connection errors are handled more clearly. Incomplete cloud responses are no longer pasted as successful results.
- Normal transcription logs omit the full text; History follows your retention settings.
- The app has its own icon, settings directory, and release channel.

Codex mode sends audio to OpenAI and uses an unsupported internal endpoint. Compatibility and account access are not guaranteed. Local speech models remain available.

This initial macOS Apple Silicon binary is ad-hoc signed and not notarized. Apple Intelligence post-processing is unavailable in this build.
